##项目资源管理平台##
Test Resource Management Platform

基于 Flask + Vue + MySQL 开发的前后端分离测试资源管理系统，面向测试团队提供从测试用例管理、计划制定到执行统计的完整流程支持。
Python
Flask
Vue
MySQL

##项目功能模块##
项目与模块管理	项目创建、模块划分、资源隔离
测试用例管理	用例 CRUD、批量导入导出、分类、版本记录
测试任务与测试集	测试集组织、计划创建、周期管理
用例执行	执行状态、结果记录、附件上传
评审管理	评审流程、意见记录、状态流转
报表统计	用例分布、通过率、缺陷统计
用户权限	账号管理、角色权限控制
